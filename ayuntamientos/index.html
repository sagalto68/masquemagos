¿CÓMO FUNCIONA?

¿Qué información hace falta para pedir presupuesto?

Con la fecha, el tipo de celebración, el espacio disponible y el público esperado ya se puede preparar una propuesta. Cuantos más detalles se faciliten, mejor se puede ajustar.

¿Quién decide el formato del espectáculo?

No hace falta tenerlo decidido de antemano. Según el tipo de evento —fiesta patronal, feria medieval, cabalgata, actividad para mayores...— se recomienda el formato de espectáculo que mejor funciona en cada espacio y con cada público.

¿Qué incluye el servicio?

Habitualmente incluye todo: material, equipo de sonido, montaje y desmontaje.

*Si el ayuntamiento se encarga del montaje, las sillas u otros elementos del espacio, también es posible ajustar el presupuesto y cobrar solo el caché del mago.

¿Hay también programación de temporada de teatros municipales?

Sí. Además de las fiestas puntuales, también hay disponibilidad para programación de temporada en teatros municipales, con espectáculos pensados para llenar sala a lo largo del año.
